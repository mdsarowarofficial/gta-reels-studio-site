Install in 3 steps

  1. Click Download for Windows and run the installer.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. The installer is not code-signed yet.
  3. Open GTA AI Reels Studio from the Start menu. The first start guides you through setup.
YouTube upload: when you connect YouTube, Google may say "Google hasn't verified this app". Click Advanced, then Go to GTA Reels Studio. Updates: the app tells you when a new version is available and only downloads it when you click Update.
