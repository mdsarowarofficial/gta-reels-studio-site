Privacy Policy - GTA Reels Studio

Last updated: 24 November 2026

What the app is

GTA Reels Studio is a desktop application that runs entirely on the user's own Windows PC. It has no server of its own and the developer does not receive, store or see any user data.

YouTube / Google user data

If you choose to connect YouTube, the app asks Google for permission to upload videos to your channel and to read basic information about your channel (its name), using the YouTube Data API. The app uses this access only to upload the videos that you select and approve, with the title, description and privacy setting you choose.

  • The sign-in token Google gives the app is stored only on your own PC, in the Windows Credential Manager or an encrypted local file.
  • No Google user data is sent to the developer or to any third party, and none is sold, shared or used for advertising.
  • Videos are sent only from your PC directly to YouTube when you press upload.

Revoking access

You can disconnect YouTube inside the app, which deletes the stored token. You can also remove access at any time at myaccount.google.com/permissions.

YouTube API Services

GTA Reels Studio uses YouTube API Services. By using it you also agree to the YouTube Terms of Service and the Google Privacy Policy.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
